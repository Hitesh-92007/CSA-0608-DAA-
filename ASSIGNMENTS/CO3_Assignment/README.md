## Questions

1. Max/Min by divide and conquer and Binary Search
2. Merge Sort and Quick Sort decomposition comparison
3. Schoolbook and Karatsuba integer multiplication
4. Conventional and Strassen matrix multiplication
5. Brute-force and divide-and-conquer closest pair
6. Median of Medians and Meet-in-the-Middle subset sum
7. A divide-and-conquer design for maximum subarray sum
