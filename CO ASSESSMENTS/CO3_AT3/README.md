# CO3 AT3 case study: KartIQ divide-and-conquer design

**Student:** Hitesh C (Register number 192524005)  
**Course:** CSA06 - Design and Analysis of Algorithms  
**Case study:** Divide-and-Conquer Engine of KartIQ  
**Instructor:** Dr. F. Mary Harin Fernandez  
**Due date shown in the question:** 5 October 2027

This submission covers all six requested parts: case understanding, Merge Sort, Quick Sort, Binary Search, Strassen multiplication, and the final platform design. The four sample datasets are implemented and run. Production calculations use the workloads in the question: 10,000,000 orders, 100,000 sellers, and 1,024 by 1,024 matrices.

## Repository layout

- `Module_1_Merge_Sort/` contains stable order sorting, pseudocode, source, and its report.
- `Module_2_Quick_Sort/` contains the first-pivot baseline, guarded optimized Quick Sort, pseudocode, source, and its report.
- `Module_3_Binary_Search/` contains first-occurrence timestamp search, pseudocode, source, and its report.
- `Module_4_Strassen_Matrix_Multiplication/` contains classical and Strassen multiplication, pseudocode, source, and its report.
- `Final_Design_and_Analysis/` contains the full report in Markdown, Word, and PDF, plus the final design, recommendations, and the Word-report builder.
- `Supporting_Files/` contains sample datasets, reproducible test and benchmark scripts, measured outputs, charts, and screenshot evidence.

## Run the work

Run these commands from the `CO3_AT3` folder with Python 3.10 or later:

```text
python Supporting_Files/run_case_study.py
python Supporting_Files/test_harness.py
python Supporting_Files/run_experiments.py
python Supporting_Files/create_charts.py
```

The test harness checks stable ties, empty and boundary inputs, first-pivot partitioning, the introsort heap fallback, duplicate timestamps, matrix padding, and randomized equivalence against Python's trusted sort or conventional matrix multiplication.
